Organizador de arquivos HTML

Leia a pasta de origem e a pasta de destino. O programa extrai a tag <title>, identifica cópias idênticas e organiza os nomes por data, respeitando versões já existentes.

Compatibilidade: use o app publicado no GitHub Pages por HTTPS, preferencialmente no Chrome/Edge para computador. O navegador solicitará acesso às pastas. Tudo é processado no dispositivo, sem enviar arquivos para servidores. Em navegadores sem acesso a pastas, use Chrome/Edge atualizado.
